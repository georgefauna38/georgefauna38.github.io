# 🔴🟡 Четыре в ряд (Connect 4) — Веб-игра с ИИ

Современная, стильная и адаптивная реализация классической настольной игры **«Четыре в ряд»** (Connect 4), написанная на чистых HTML5, CSS3 (Tailwind CSS) и JavaScript. В игре реализован умный искусственный интеллект с 4 уровнями сложности, звуковые эффекты через Web Audio API и анимация гравитационного падения фишек.

## ✨ Особенности

* **🎨 Уютный UI/UX дизайн:** Объемная 3D-доска, приятные градиенты, полупрозрачные панели в стиле Glassmorphism и неоновая подсветка победных линий.
* **🎥 Плавные анимации:** Анимированное падение фишек с эффектом отскока и визуальная подсказка выбранного столбца при наведении.
* **🤖 4 Уровня сложности бота:**
  * **Легкий (Easy):** Делает случайные ходы. Идеально для детей и новичков.
  * **Средний (Medium):** Использует тактические эвристики (блокирует очевидные победы игрока и строит свои).
  * **Сложный (Hard):** Классический алгоритм **Minimax** с **Alpha-Beta отсечением** (глубина 5 ходов).
  * **🔥 Мастер (Grandmaster):** Усиленный **Minimax (глубина 8+ ходов)** с хешированием по Зобристу (**Zobrist Hashing**), Таблицей Транспозиций (**Transposition Table**) и сортировкой ходов (**Move Ordering**).
* **🔊 Встроенные звуки:** Реалистичные звуки падения фишек и победные фанфары без внешних MP3-файлов (сгенерированы на лету через `Web Audio API`).
* **📱 Полный Responsive:** Игра отлично адаптируется под экраны любых устройств (смартфоны, планшеты, ПК).
* **⚡ Без зависимостей (Zero Dependencies):** Запускается прямо в браузере без сборщиков (Webpack/Vite) и Node.js.

## 🧠 Как работает искусственный интеллект (ИИ)?

ИИ анализирует игровое поле как **дерево решений с нулевой суммой**:

1. **Алгоритм Minimax & Alpha-Beta Pruning:** Бот моделирует варианты развития событий на несколько ходов вперед, максимизируя свои шансы и минимизируя выгоду игрока. Alpha-Beta отсечение позволяет отбрасывать заведомо проигрышные ветки дерева.
2. **Move Ordering (Сортировка ходов):** Проверка столбцов начинается с центрального (3-го) и отходит к краям `[3, 2, 4, 1, 5, 0, 6]`. Это оптимизирует Alpha-Beta отсечение, заставляя алгоритм отбрасывать до 90% неперспективных веток на первых шагах.
3. **Zobrist Hashing & Transposition Table:** На уровне «Мастер» бот рассчитывает уникальный хеш позиции доски и сохраняет оценки веток в память. Если позиция повторяется при другой последовательности ходов, результат берется из памяти мгновенно.

## 🚀 Быстрый запуск

### Запуск локально:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/connect4-game.git
   ```
2. Откройте файл `index.html` в любом современном браузере.

### Публикация на GitHub Pages:
1. Перейдите в настройки репозитория (**Settings**).
2. Выберите раздел **Pages**.
3. В поле **Source** выберите ветку `main` (или `master`) и нажмите **Save**.
4. Игра будет доступна по адресу `https://ваш-username.github.io/connect4-game/`.

## 📜 Правила игры

* Игроки по очереди сбрасывают фишки в столбцы вертикальной доски.
* Фишка падает на самую нижнюю свободную ячейку выбранной колонки.
* Победителем становится тот, кто первым выстроит **4 фишки своего цвета в ряд** по горизонтали, вертикали или диагонали.
